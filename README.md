# STM32 轮足机械狗嵌入式控制

> 面向 12 自由度轮足机器人的 STM32F407 控制程序。项目基于 uC/OS-II 实时操作系统，实现四足步行与轮式运动两种工作模式，并集成姿态感知、遥控输入、跳跃控制和执行器驱动。

## 项目定位

本项目将四足机器人步态控制与轮式底盘控制部署到 STM32F407。主控制任务以 5 ms 周期运行，负责处理 IMU 姿态、遥控指令、模式切换、运动学求解与电机输出。

项目名称中的“三模态”包含四足、轮式和飞行三类设计方向；当前代码实际实现并接入控制流程的是四足与轮式模式，飞行控制仅保留占位结构。

## 硬件与软件平台

| 类别 | 配置 |
| --- | --- |
| 主控 | STM32F407，Cortex-M4，Keil MDK / ARM Compiler 6 |
| 实时系统 | uC/OS-II |
| 关节执行器 | 12 路 HTS-35H 串行总线舵机，通过 USART3 半双工与 DMA 批量发送控制帧 |
| 轮式执行器 | 4 路 RM3508 轮毂电机，CAN1 通信与 PID 速度控制 |
| 姿态传感器 | ICM-42688-P，硬件 I2C 读取并进行姿态融合 |
| 遥控输入 | SBUS 协议，经蓝牙链路接入 USART6 |

## 核心功能

- 通过步态生成器、调度器和四条腿的独立状态机实现 Trot、Walk、Pronk、Pace、Bound 等步态框架。
- 使用三次贝塞尔曲线规划摆动足端轨迹，并以几何法逆运动学将目标足端位置转换为关节角度。
- 对 pitch、roll 使用 PD 控制，对 yaw 使用 PID 控制，通过支撑腿足端位置修正改善机身姿态。
- 支持站立、四足步行、轮式、收腿和展开等姿态与模式过渡；轮式模式采用差速模型生成轮毂电机速度指令。
- 实现基于遥控器边沿事件的模式切换和五阶段跳跃序列：下蹲、蹬地、腾空、落地、恢复。
- 通过 DMA 批量输出舵机控制帧，并对危险动作使用带超时保护的发送路径。

## 控制架构

```text
SBUS 遥控 / ICM-42688-P
          ↓
     5 ms 主控制任务
          ↓
模式管理 ──→ 四足步态控制 ──→ 单腿状态机 × 4 ──→ 逆运动学 ──→ 12 路舵机
    │
    └────────→ 轮式差速控制 ───────────────────────────────→ 4 路轮毂电机
```

## 关键实现

| 模块 | 实现内容 |
| --- | --- |
| 实时任务 | `upctrl_task` 以 5 ms 周期执行主控制循环，完成传感器、控制和执行器输出的协调。 |
| 步态系统 | 全局相位驱动四腿支撑/摆动切换；单腿状态机同时管理四足、轮式、收腿和展开过程。 |
| 运动学 | 实现单腿正运动学与几何法逆运动学，并处理关节限位与不可达工作空间。 |
| 姿态控制 | 利用 IMU 角度反馈进行 PD/PID 修正，补偿俯仰、横滚和偏航偏差。 |
| 执行器控制 | 串行舵机采用 USART3 与 DMA；轮毂电机采用 CAN1 与速度 PID。 |
| 遥控与动作 | 解析 16 通道 SBUS 数据，支持模式选择、速度缩放与跳跃触发。 |

## 工程入口

- Keil 工程：`USER/F407Practice.uvprojx`
- 程序入口：`USER/main.c`
- 主控制任务：`USER/UpctrlTask.c`
- 核心控制库：`Tri-modal robot/`
- 全局参数：`Tri-modal robot/robot_config.h`

## 构建方式

1. 使用 Keil MDK 打开 `USER/F407Practice.uvprojx`。
2. 选择 ARM Compiler 6 与目标芯片 STM32F407。
3. 根据硬件连接检查 `robot_config.h` 中的执行器与控制参数。
4. 编译并下载到开发板。
